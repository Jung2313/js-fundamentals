# Sistema de inscripción a un curso

Programa de consola que simula la inscripción de estudiantes a un instituto.
Valida los datos de cada estudiante, les asigna un nivel según su edad,
y genera un reporte final de inscripciones exitosas y rechazadas.

## Conceptos practicados

- Hoisting
- Condicionales con switch y switch(true) para rangos
- Bucle for...in para recorrer objetos
- Bucle for...of para recorrer arrays
- Manejo de errores con try/catch y throw
- Validación de datos con el objeto Error
- Manipulación de objetos con notación de corchetes
- Contadores y acumuladores

## Cómo ejecutarlo

​```bash
node inscripcion.js
​```
